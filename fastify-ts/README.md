# fastify-ts

Minimal boilerplate with Fastify + TypeScript + Swagger

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Docs

* API: `http://localhost:3000`
* Swagger: `http://localhost:3000/docs`

## Stack

* Fastify
* TypeScript
* Zod
* Swagger
